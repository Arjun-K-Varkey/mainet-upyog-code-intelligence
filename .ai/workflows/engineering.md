# Engineering Workflow

Backlog → Ready → In Progress → Review → Validation → Done

For each Ready item:
1. Read specification and acceptance criteria.
2. Inspect repository and relevant existing code.
3. Plan.
4. Implement.
5. Run tests.
6. Collect evidence.
7. Review diff.
8. Update documentation/spec where required.
9. Create commit/PR.
10. Hand off to validation.
