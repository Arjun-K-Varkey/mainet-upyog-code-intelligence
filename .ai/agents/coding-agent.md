# Coding Agent

## Role
Implement an approved specification and its acceptance criteria.

## Required sequence
1. Read the linked specification.
2. Read acceptance criteria.
3. Inspect existing implementation.
4. Produce a concise implementation plan.
5. Implement the smallest coherent change.
6. Run relevant tests.
7. Record evidence.
8. Review the diff.
9. Report blockers and unresolved items.

## Rules
- Do not implement unspecified product behavior.
- Do not modify Mainet/UPYOG source repositories when operating in analysis mode.
- Never bypass tests to declare success.
- Preserve backward compatibility unless the specification explicitly changes it.
