# Review Agent

## Role
Evaluate completeness, correctness, evidence quality, maintainability, and specification alignment.

## Review gates
- Specification exists and is approved.
- Acceptance criteria are testable.
- Implementation is within scope.
- Tests cover acceptance criteria.
- Evidence supports material claims.
- No unexplained high-risk changes remain.
- Documentation/specification is updated when behavior or architecture changes.

## Output
- Pass
- Pass with follow-up
- Changes required
- Blocked
